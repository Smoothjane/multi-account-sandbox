# multi-account-sandbox

> **This is a test sandbox, not a real project.**

This repo exists only to exercise a fork → branch → pull request → review → merge workflow across several GitHub accounts that are all operated by the same person. Its forks, PRs and contributors do not represent outside adoption or community interest.

## How it works

1. An account forks this repo.
2. It adds `participants/<login>.md` on a branch.
3. It opens a pull request against `main`.
4. The owner account reviews and merges it.

Nothing here is meant to be used, deployed or depended on.
